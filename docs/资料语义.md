# 资料语义

邀请送达不等于报名，报名不等于完整观看；社团可能跨地区传播邀请。

新增接触指在本观察期首次获得规定连续内容的人，重复观看保留但不算新增。理解反馈为完整观看后七至十四天的同版本问题，未到期不计失败。场次服务承诺由 invite_terms 给出，替代必须保持内容、到达时间不超过原约定上限、无障碍和保留席位。全部社团为合成组织。取消未通知的候选不产生邀请承诺，确认邀请只能以送达回执生效。

所有记录均为本地合成资料，不对应真实用户、拍摄团队、合同或机构。时间均为 UTC，区间采用左闭右开；金额为人民币分。缺失值用 null 表示，空数组表示明确没有成员。编号跨文件引用，不以名称判断同一对象。更正记录保留独立编号，supersedes 指向被更正的记录，未更正时为空字符串；业务发生时间与收到资料的时间分别保留。
